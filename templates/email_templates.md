# 保研邮件模板集

## 1. 导师套磁邮件（首次联系）

```
主题：XX专业推免咨询 - XX大学XXX

尊敬的X教授：

您好！

我是XX大学XX专业大X的本科生XXX，专业排名X/XX（前X%）。
我对您在XX方向的研究非常感兴趣，特别是您近期发表的论文《XX》中关于XX的工作。

我在本科期间的科研经历如下：
- XX项目（简述你的贡献和成果）
- XX论文（标注状态：已发表/在投/准备中）

我非常希望能有机会加入您的课题组攻读研究生。
随信附上我的简历和成绩单，供您参考。

如果您方便的话，希望能有机会与您面谈或线上交流。
感谢您的时间，期待您的回复！

此致
敬礼

XXX
XX大学XX专业
邮箱：xxx@mail.ustc.edu.cn
```

## 2. 套磁跟进邮件（2周后无回复）

```
主题：Re: XX专业推免咨询 - XX大学XXX

尊敬的X教授：

您好！冒昧再次打扰。

我于X月X日给您发过一封关于推免咨询的邮件，不知您是否方便查阅。
近期我又阅读了您课题组的新作《XX》，更加坚定了希望加入您课题组的想法。

如果目前课题组还有招生名额，恳请您能给予回复。
如不便回复也完全理解，感谢您的时间！

此致
敬礼

XXX
```

## 3. 推荐信请求邮件

```
主题：恳请X老师撰写推免推荐信 - XXX

尊敬的X老师：

您好！我是XX专业大X的XXX，曾选修您的XX课程并取得XX成绩。

我正在准备保研申请，目标院校包括XX、XX等。
鉴于您对我的学习情况比较了解，冒昧恳请您能为我撰写一封推荐信。

我已准备了简历、个人陈述等材料供您参考。
推荐信的截止日期为X月X日。

非常感谢您的帮助！

此致
敬礼

XXX
```

## 注意事项

- 每封邮件都要个性化，不要群发模板
- 同一院系不要联系多位导师
- 附件命名规范：简历_姓名_学校.pdf
- 邮件发送时间：工作日上午9-11点最佳
