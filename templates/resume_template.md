# 保研简历模板要点

## 基本结构（一页纸）

```
┌─────────────────────────────────────────┐
│ 姓名 | 学校 | 专业 | 年级              │
│ 邮箱 | 电话 | GitHub/个人主页           │
├─────────────────────────────────────────┤
│ 教育背景                                 │
│ - GPA: X.XX/4.0  排名: X/XX (前X%)     │
│ - 核心课程: XX(95) XX(92) XX(90)       │
├─────────────────────────────────────────┤
│ 科研经历                                 │
│ - 项目名称 | 角色 | 时间                │
│   · 具体做了什么（量化成果）             │
│   · 用了什么方法/技术                    │
│   · 取得了什么结果                       │
├─────────────────────────────────────────┤
│ 论文发表                                 │
│ - 作者列表. 论文题目. 会议/期刊, 年份.  │
│   (状态: 已发表/在投/准备中)             │
├─────────────────────────────────────────┤
│ 竞赛获奖                                 │
│ - 竞赛名称 | 奖项 | 时间                │
├─────────────────────────────────────────┤
│ 技能                                     │
│ - 编程: Python, C++, PyTorch, ...       │
│ - 工具: Git, Linux, LaTeX, ...          │
│ - 语言: 英语六级XXX / 托福XX / 雅思X.X  │
└─────────────────────────────────────────┘
```

## 写作原则

1. **一页纸**: 中英文各一版，不超过一页
2. **量化成果**: "提升了15%准确率" 比 "取得了良好效果" 好
3. **突出重点**: 科研经历占最大篇幅，与目标方向无关的经历可省略
4. **动词开头**: "设计了..." "实现了..." "发表了..."
5. **格式统一**: 字体、间距、日期格式保持一致
