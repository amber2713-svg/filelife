# 保研Agent - 作品简介

## 一句话介绍

基于 ReAct + Function Calling 的自主保研规划智能体——Agent 自主搜索信息、分析数据、生成个性化攻略。

## 解决什么问题

保研信息分散、流程复杂、竞争激烈。学生需要查询院校政策、准备材料、联系导师、规划时间线，工作量大且容易遗漏关键节点。保研Agent 将这些工作自动化：用户只需描述自己的背景和目标，Agent 自主完成信息收集、分析和攻略生成。

## 核心技术亮点

### 1. 真正的自主决策

不是预设的"7个Prompt依次执行"流水线，而是基于 **ReAct（Reasoning + Acting）** 模式的自主智能体：

- Agent 自主决定调用什么工具、搜索什么信息
- 根据中间结果动态调整下一步行动
- 信息充足后自主判断并生成最终攻略

### 2. OpenAI Function Calling

通过标准的 Function Calling 接口，Agent 可自主调用 6 个工具：

| 工具 | 功能 |
|------|------|
| `web_search` | 搜索最新院校政策、夏令营通知 |
| `web_fetch` | 抓取网页详细内容 |
| `knowledge_base_query` | 查询保研知识库 |
| `knowledge_base_list` | 列出知识库主题 |
| `template_render` | 渲染套磁邮件等模板 |
| `template_list` | 列出可用模板 |

### 3. 思维链实时可视化

Web 界面实时展示 Agent 的推理过程：
- 💭 思考步骤（Agent 在分析什么）
- 🔧 工具调用（调用了什么工具、什么参数）
- 📋 观察结果（工具返回了什么）
- 最终生成完整 Markdown 攻略

评委可以"看到" Agent 如何一步步推理和决策。

### 4. 多级降级容错

- API 可用时：调用真实 LLM 进行推理
- API 不可用时：Mock 模式模拟完整 ReAct 过程，无需任何外部依赖即可演示

## 技术栈

- **后端**: Python 3.12 + Flask
- **LLM**: 中科大 API (GLM-5.2) + OpenAI SDK
- **Agent**: ReAct + Function Calling
- **前端**: 原生 JS + SSE 流式渲染
- **部署**: Render

## 使用方式

1. 打开 Web 应用
2. 输入个人背景（学校、专业、绩点、科研经历、目标院校等）
3. Agent 自主搜索信息、查询知识库、分析数据
4. 实时观看 Agent 推理过程
5. 获得完整的个性化保研攻略

也可点击"一键演示"，使用预设的中科大 CS 学生背景，快速体验完整流程。

## 运行效果

- Agent 通常执行 10-15 轮 ReAct 循环
- 调用 4-6 次工具（知识库查询、搜索等）
- 生成 2000+ 字的完整攻略，包含：SWOT 分析、时间线、条件准备、院校选择、材料清单、面试指南、避坑提醒
